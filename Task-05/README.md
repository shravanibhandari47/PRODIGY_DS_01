#Task 05 – Traffic Accident Data Analysis

Objective
Analyze traffic accident data to identify patterns related to road conditions, weather, and time of day. Visualize accident hotspots and contributing factors.

Analyzed accident severity

Studied road conditions

Compared accident severity across weather conditions
Examined road and infrastructure factors
Created day-hour heatmaps
Identified accident hotspots
Created an interactive geographic hotspot visualization
